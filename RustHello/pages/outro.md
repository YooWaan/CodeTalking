# Outro


<span class="text-lg">Positive</span>

* Given these days' trend and technical benefits, it might be a better option to build a backend system.
* Without a extra tool installation, a developer can build an application.
  * Compiler tells what is wrong and after fixing it, a program is safe basically.


<span class="text-lg">Negative</span>

* If a developer doesn't have programming experience with awareness of memory allocation and management, it's hard to code a library or application.
* Build speed is slower than c/c++, golang and zig compiler
* For cross os building, it's a bit hassle.
